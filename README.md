# Todo List Manager

A simple Todo List Manager built using Spring Boot. This application allows me to create, view, update, and delete tasks, helping me organize the daily activities efficiently.

## Features

- Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks
- Mark tasks as completed
- Store tasks in a MySQL database
- Responsive and clean user interface

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Data JPA

### Frontend
- HTML
- CSS
- Thymeleaf

### Database
- MySQL

### Build Tool
- Maven
